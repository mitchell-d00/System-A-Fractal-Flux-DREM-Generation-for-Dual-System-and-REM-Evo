# Welcome to the McPhetridge Research Framework

## What This Is

This is **constraint-first epistemic infrastructure** designed to prevent three critical failure modes in complex systems:

1. **Narrative immunity** – where failure gets reinterpreted as depth
2. **Universal capture** – where a framework explains everything, predicts nothing
3. **Authority drift** – where correctness depends on author interpretation

This framework is **not** a theory, worldview, or metaphysics. It is a **pruning machine** for ideas.

## The Operator Vocabulary: Φ / F / ∇H

These are **instrumental diagnostics**, not claims about reality.

### Φ – Continuation (Update Under Pressure)

Represents how a system evolves through recursive update:

```
R_{t+1} = Φ(R_t) + noise
```

- Models temporal dynamics
- Tracks how candidates persist or diverge
- Used diagnostically to identify continuation-engine boundaries

**Falsifiers (kill conditions):**
- Φ collapses into generic nonlinear damping
- Φ cannot distinguish from random perturbations
- Φ requires metaphysical interpretation to survive

### F – Scale Reconciliation (Cross-Scale Coherence)

Represents how a system maintains coherence across scales:

```
I(F_κ[R]; R) = cross-scale mutual information
```

- Models whether fine and coarse structure cohere
- Identifies scale-dependent failure modes
- Tests whether "identity" requires cross-scale regulation

**Falsifiers:**
- Structure is only fine-scale
- Coarse-scale dynamics add nothing
- Scale independence means identity is trivial

### ∇H – Stabilization (Anti-Dispersion Gradient)

Represents pressure that prevents drift under perturbation:

```
∇H = -λ(representational entropy)
```

- Models constraint enforcement
- Tracks whether stability requires active regulation
- Identifies when persistence is automatic vs maintained

**Falsifiers:**
- Stability occurs without ∇H pressure
- ∇H is just friction with no selectivity
- Perturbation doesn't actually challenge survival

## The Straight-Line Boundary

**When recursion must shut off:**

If a problem admits:
- ✅ Closed-form analytic solution
- ✅ No recursive stabilization loop required
- ✅ No entropy gradient shapes outcome
- ✅ No attractor competition exists
- ✅ No falsifier search remains

**Then:** The bridge language must terminate.

**Rule:** Pre-pruning uniqueness means no work occurred.

```
If |S₀| = 1 before any elimination → Straight-Line Boundary applies
If |S₀| > 1 and elimination occurred → Recursion was earned
```

**Host-Domain Adjudication:**
When analytic closure exists, host-domain primitives have priority. The bridge language may diagnose, clarify, or analyze—but it must defer to the host domain's result.

## Key Concepts

### Big Space
The field of all coherent models prior to constraint.
- **Not** the space of all possibilities (infinite)
- **Is** the space of all admissible candidates under host-domain rules
- Gets pruned by System B into a much smaller survivor set

### Survivor Set (S_t)
Candidates that have passed elimination at step t.
- Must have non-zero falsifiers
- Must have passed stress tests
- Must show measurable constraint sensitivity

### Deductive Collapse
When a single unique answer emerges from competing candidates.
- **Earned collapse:** occurred via eliminative pressure
- **Trivial collapse:** uniqueness existed from the start (Straight-Line Boundary applies)

### The Moment
High-fidelity coincidence between operation and meta-state.
- Measured via information-theoretic synchrony
- Not mysticism; operationally defined
- Relevant to recursive systems only

### Load
Exposure to heterogeneous constraint environments that would break weak frameworks.
- **Not** academic peer review
- **Not** consensus or popularity
- **Is** adversarial perturbation, hostile precision, and punishing ambiguity

### Regime
A fixed set of constraints + host domain + resolution + perturbation set.
- Must be preregistered before pruning begins
- Cannot change mid-run (signals ideology)
- Enables reproducibility

### Mistake 1: Using the framework to answer domain questions
- ❌ Wrong: "REM-Evo says the answer is..."
- ✅ Right: "Physics says the answer is. REM-Evo reveals what made this answer robust."

### Mistake 2: Invoking author authority
- ❌ Wrong: "McPhetridge intends this to mean..."
- ✅ Right: "Independent operators converged on this constraint mapping."

### Mistake 3: Expanding Big Space after elimination
- ❌ Wrong: "But what if there were deeper multiplicity..."
- ✅ Right: "Big Space was frozen at t₀. Additional candidates require a new regime."

### Mistake 4: Surviving through reinterpretation
- ❌ Wrong: "The failure actually shows the framework is deeper"
- ✅ Right: "Kill condition triggered. Narrating the failure is forbidden."

### Mistake 5: Not terminating at the Straight-Line Boundary
- ❌ Wrong: "Recursion applies everywhere"

### Mistake 6: Using metaphor as evidence
- ❌ Wrong: "The stability suggests the system has agency"
